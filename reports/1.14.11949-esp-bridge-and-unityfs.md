## Remaining blocker before delivering an APK

The bridge **cannot see players** unless an authorized in-game source provides a valid per-frame view-projection matrix and real player positions. We have not proved whether enemy positions are replicated to the client when occluded. The live `libil2cpp.so` method mapping is still obstructed by nonstandard metadata and the original `libloader.so` crashes on x86_64 Android ARM translation.

Next meaningful validation: recover an authorized runtime camera+entity snapshot provider on native ARM64, verify whether the server sends occluded enemies, integrate an app-owned renderer, and run complete Android process tests. Never label the C ABI library an ESP injector or claim zero crashes without that evidence.
