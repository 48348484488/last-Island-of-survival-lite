- `virtual_overlay_feed_multi.sh`: real virtual Android ADB test driver.
- `check_virtual_feed_multi.py`: fail-closed screenshot/pid/log validation.

**Not proven:** player location acquisition from Oxide, actual game camera access, any multiplayer ESP, operation against an original game process, or security-protection compatibility. No game APK was loaded or modified during the experiment. This is a standalone diagnostic overlay test using invented positions.
