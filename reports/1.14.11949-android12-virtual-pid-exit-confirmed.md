## Confirmed direct Activity-to-PID association

The original Activity, while top-resumed in Android dumpsys, included:

    mResumedActivity: ActivityRecord{... com.catsbit.oxidesurvivalisland/cTOOT3.abKmV1.tP0Gr1.OxideActivity ...}

In the SAME ActivityRecord task block, Android explicitly associated:

    app=ProcessRecord{... 1829:com.catsbit.oxidesurvivalisland/u0a70}

The rapid concurrent pidof sampling first saw PID 1829 during startup and
observed it for **31 samples**, then recorded that the PID was absent.
This process was observed well before the Activity finished.

The original-game PID-scoped Android logcat analyzer recorded a
self-directed SIGKILL from that SAME PID 1829. Android's ApplicationExitInfo
recorded:

    timestamp=2026-10-14 00:08:29.328
    pid=1829
    process=com.catsbit.oxidesurvivalisland
    reason=2 (SIGNALED)
    subreason=3 (TOO MANY EMPTY PROCS)
    status=9

The subreason is an Android-reported exit-info field. It does not override
the separately observed same-PID self-SIGKILL; neither field identifies the
specific game security rule or what triggered the screen warning.

**FINAL VERIFIED CLASSIFICATION**: ORIGINAL_ACTIVITY_PID_AND_SIGNAL_CONFIRMED.

The earlier am_proc_start-only classifier reported ORIGINAL_ACTIVITY_START_NOT_FOUND
because the Android 12 events buffer had not supplied that marker.
That result was incomplete and is superseded by the ActivityRecord + PID
sampling + exit-info correlation.

- Native ARM64 Android 12: original loading UI/security warning; game Activity

- Native ARM64 Android 14: original loading UI/security warning; self-directed SIGKILL.
- Official Google Play x86_64 emulators (Android 14, 15, 16) are a distinct
  failure: the Berberis ARM64 translator rejects the original libloader
  ID_AA64PFR1_EL1 MRS opcode and emits SIGILL.

None of these observations proves the specific reason Oxide's own warning
was triggered. Google Play services absence, security policy, unsupported
GPU/sensors and other runtime dependencies remain hypotheses, not identified
root causes.
