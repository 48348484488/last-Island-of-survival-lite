# Oxide 1.15.11966 — Cuttlefish ARM64 host decision (2026-10-16)

## Goal and boundary
Original four APKs unchanged; original Activity and same PID >=35s, verified interactive menu/gameplay. This document is a public-documentation preflight, **not** an APK execution.

## Candidate
Official AOSP Cuttlefish ARM64: https://source.android.com/docs/devices/cuttlefish/get-started
Cuttlefish is a downloadable, legitimate ARM64 Android virtual-device stack. Native ARM64 would avoid the *specific* x86_64 Berberis translation fault previously observed. It does not establish Oxide compatibility, Play Store support/certification, or a 35-second Activity.

## Host gate — fail closed
GitHub's current hosted runner documentation explicitly says nested virtualization is unsupported on macOS ARM64:
https://docs.github.com/en/actions/reference/runners/github-hosted-runners
Linux ARM64 Actions run #38899371688 already found /dev/kvm absent. Windows ARM64 Actions run #38899889965 found WHvGetCapability(HypervisorPresent)=false. Combined gate #38900463282 denied heavy trials. The GitHub runner-images issue #13505 also reports Hypervisor.framework support unavailable on hosted Apple Silicon runners:
https://github.com/actions/runner-images/issues/13505

## Decision
**NO-GO on all currently verified GitHub-hosted ARM64 runners.**
No Cuttlefish image download, Android boot, APK transfer, installation, or security bypass. An AOSP image cannot be assumed to provide official Google Play services or certification. No gameplay proof.

## Distinct prerequisite for reconsideration
Require **new verifiable evidence** of an already accessible, legitimate ARM64 host with working KVM or equivalent hardware acceleration and compatible Android image/services. Perform a cheap host-only acceleration probe first, then verify system image provenance and service requirements, and only then consider a bounded heavy experiment with explicit timeout and stop on original PID death/security notice. Never retry the same blocked hosts merely because the CI passes.

## CI and evidence
Offline provider gate run #38923107627: 11 tests passed, artifact #12055891781. This validates metadata only. The original Activity remains unverified at >=35s.
