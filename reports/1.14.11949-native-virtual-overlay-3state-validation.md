## Verified scope and outstanding work

- **Proved:** Native ARM64 Android app can load C++ projection through JNI,
  show a transparent green rectangle over the Android launcher with controlled
  inputs, reject missing/stale inputs, and clean the overlay when the app exits.
- **Not proved:** World coordinates from Oxide, game memory acquisition, live
  entity/player IDs, player camera matrices, game UI/menu operation or
  a genuine multiplayer ESP. No original game package was used in this run.
- **Separate unresolved blocker:** the original Oxide APK shows a security
  Toast and sends SIGKILL to itself in Redroid Android 12/13/14.
  This independent overlay test does not fix, bypass or even execute the
  game's security mechanism.
