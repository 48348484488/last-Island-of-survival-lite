## Scope

The result **proves native ARM64 bridge code can execute inside a running Android process** through Android's ARM64 translation layer in this emulator, with successful Java⇄JNI⇄C++ interoperation. Earlier host ASan/UBSan tests and Android ARM64 cross-compilation are separate validations.

This is **not** a playable Oxide build or an ESP APK. It neither runs the original game's loader, connects to a server, discovers cameras/players in Oxide, reads game process memory, nor renders real enemy boxes. The original Oxide APK previously crashed in the same x86_64 emulator at `libloader.so+0x830BEC`; the isolated JNI success does not resolve or bypass that crash.

## Blockers before the requested game ESP

1. An authorized provider of live camera matrices and real player positions from **Oxide 1.14.11949**.
2. Evidence that enemy positions are available to that client when occluded / outside AoI.
3. An actual Android in-game renderer and safe integration, followed by native-device boot/scene tests and crash logging.

Do not present the diagnostic app as ESP or claim production crash-free behavior.
