## Diagnóstico

Em VM hospedada no GitHub macOS ARM64, **a API de aceleração estar instalada não significa que o hipervisor esteja disponível**. A [documentação de `hv_vm_create()` da Apple](https://developer.apple.com/documentation/hypervisor/hv_vm_create%28_%3A%29?language=objc) define criação real de VM; o teste assinado retornou `HV_UNSUPPORTED`. A [issue do GitHub runner-images #13505](https://github.com/actions/runner-images/issues/13505) sobre suporte a Hypervisor.Framework em Apple Silicon foi encerrada sem plano de implementação. Nada nos logs atribui essa falha ao jogo.

O novo [gate macOS do M4](https://github.com/48348484488/oxide/blob/main/.github/workflows/oxide-m4-macos-arm64-original.yml) chama `hv_vm_create` antes de instalar um AVD e é **fail-closed**. [Código do gate](https://github.com/48348484488/oxide/blob/main/tools/oxide_mac_hvf_vm_create.c), [workflow rápido de prova](https://github.com/48348484488/oxide/blob/main/.github/workflows/oxide-m3-macos-hvf-create-preflight.yml), [regressões](https://github.com/48348484488/oxide/blob/main/tests/test_oxide_macos_hvf_gate.py). O supervisor foi alterado para classificar `BLOCKED_HVF_UNSUPPORTED` como **falha do host, não do Oxide**.

## Próxima ação responsável, sem pedir nada ao usuário

- Não iniciar outro boot Android oficial em Ubuntu x86_64 (arquitetura incompatível) ou macOS Apple Silicon GitHub com `HV_UNSUPPORTED`, salvo mudança demonstrada no suporte de virtualização.
- Para novo host virtual, executar um **preflight barato real**: arquitetura ARM64, hipervisor utilizável (KVM ou `hv_vm_create`), e somente depois instalar AVD e APKs originais.
- Enquanto não houver host adequado, pode-se evoluir testes offline, diagnóstico do fechamento do jogo no Redroid e overlay independente com dados sintéticos, **sem** afirmar que o jogo está executando.
- Para validar a meta de 35 s, exigir Activity original retomada, mesmo PID, screenshots e logcat. Mesmo isso ainda exige validação visual/interação para contar gameplay.

**Nenhum host oficial ARM64 com Google Play foi comprovado inicializado nesta matriz.** Redroid ARM64 executou o original até o carregamento, mas terminou prematuramente. Nenhuma infraestrutura paga será criada automaticamente.
