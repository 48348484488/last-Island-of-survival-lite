# Oxide 1.15.11966 — Unity/Burst no Android ARM64 nativo (replay offline)

**Fontes:** logcats originais do [Redroid Android 15 #38789434979](https://github.com/48348484488/oxide/actions/runs/38789434979) e [Redroid Android 16 #38787025289](https://github.com/48348484488/oxide/actions/runs/38787025289), ambos com os quatro APKs originais inalterados. Os artefatos ZIP existentes têm 3,9 MB e 1,4 MB respectivamente. **Não houve novo boot nem novo download de APK.**

## Últimas etapas observáveis do processo original

| Marco a partir do START da Activity | Android 15 ARM64 (PID 2023) | Android 16 ARM64 (PID 2108) |
|---|---:|---:|
| Identificação Unity/IL2CPP | +549 ms | +553 ms |
| `Product Name: OXIDE` | +848 ms | +950 ms |
| `lib_burst_generated.so` carregada com sucesso | +4.090 ms | +4.555 ms |
| `liblib_burst_0_0.so` não localizada | +4.092 ms | +4.556 ms |
| `lib_burst_0_0.so` não localizada | +4.092 ms | +4.557 ms |
| Criação da transição CLOSE da tarefa | +4.477 ms | +4.667 ms |
| Registro de envio de SIGKILL pelo próprio PID | +4.480 ms | +4.670 ms |
| Última busca de biblioteca opcional → SIGKILL | 388 ms | 113 ms |
| CLOSE → SIGKILL | 3 ms | 3 ms |

O processo registra `Load ...lib_burst_generated.so ... : ok` em **ambos** os sistemas, seguido por duas tentativas `dlopen failed: library ... not found` para nomes distintos associados a Burst. Isso constitui **evidência de buscas que falharam**, e não de uma dependência obrigatória ausente. Bibliotecas opcionais podem ter caminhos de fallback: os logs **não** comprovam que a falha de busca provocou o encerramento, muito menos que esteja ligada à proteção do aplicativo.
