### Genuine original game crash

The exact original signed APK splits installed: Android package
manager reported SUCCESS. Explicit original OxideActivity startup
returned Android Status: ok.

Original process PID 4078 started at approximately 22:51:44.567 UTC.
At 22:51:45.825 UTC, the original game encountered:

    Fatal signal 4 (SIGILL), code -6 (SI_TKILL), pid 4078

Android exit-info confirmed native crash, signal status 4, at
22:51:47.878 UTC. The original PID had ended before the 10- and
35-second activity checkpoints, and no active OxideActivity remained.

The real native tombstone reported host ABI x86_64, guest architecture
arm64, native libc tgkill, and these guest backtrace frames:

    #00 libloader.so + 0x830BEC
    #01 libloader.so + 0x830D98
    #02 linker64: call_constructors
    #03 linker64: do_dlopen

The guest was initializing libloader.so before any confirmed Unity
or IL2CPP initialization marker. Four native-crash regression tests
passed; the same facts were reproduced from the archived real
original-game tombstone.

### What this DOES and does NOT prove

Native ARM64 Redroid (without Google packages) had already reached
Unity/IL2CPP startup and later logged self-directed SIGKILL (signal 9).
The official Play emulator with x86_64-to-ARM64 translation instead
encountered SIGILL (signal 4) inside the loader before Unity startup.

The SI_TKILL signal code indicates a thread-directed signal delivery;
it is NOT sufficient proof of an actual unsupported CPU instruction,
nor proof of a particular security-check decision. A native bridge
compatibility problem and app-initiated native termination remain
possible, and precise cause is not established.

Installing Play packages does not itself establish account licensing,
Play integrity, or game-server authorization. The next legitimate
compatibility option is to examine a NATIVE ARM64 Google-Play-supported
Android image/host, if available, and use a legitimate Play installation.

No multiplayer, player positions, camera source, crash-free game, or
in-game ESP was demonstrated.
