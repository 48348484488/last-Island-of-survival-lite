## Real experiment

No physical Android devices were used. A GitHub Linux/aarch64 runner
executed **two separate native ARM64 Redroid virtual Android containers**,
with normal guest/software graphics. Four signed original game APK splits
were SHA-256 verified and installed unmodified in both Android 12 and 14.
The 867MB Unity asset was downloaded once and reused; 13 unit tests passed.

## Critical correction: Android 12 screenshot proves original game rendered

Although Android 12's event stream lacked the am_proc_start marker
expected by our PID-based parser, its screenshot at 2 seconds clearly
shows the original Oxide loading picture and security warning:

    REF: 5600:AA4C:BIOUJV Security Threat Detected by App

Android 14's original loading screenshot shows the same warning with a
different token:

    REF: 5600:AA4C:67NXZ5 Security Threat Detected by App

Both also show Android's normal first-time immersive-mode instructional
dialog, "Viewing full screen" / "GOT IT". That dialog is not the game
menu or the reason for the security warning.

Therefore **the Android 12 game DID render its loading image and
security warning.** The automatic "original Activity start not found"
classification is limited to the parser's missing process-start event,
NOT evidence the game never started. Screenshots do not by themselves
prove an exact process PID, exit code, or multiplayer success.

### Android 14 direct SIGKILL evidence

- Original Activity process PID 1876 started at 23:58:49.063 UTC.
- Original Activity finished at 23:58:53.578 UTC.
- Game PID 1876 emitted SIGKILL to itself at 23:58:53.581 UTC.
- Android recorded death for PID 1876 at 23:58:53.621 UTC.
- No original game Activity remained top-resumed after ten seconds.

Android 12's raw event capture included an original OxideActivity finish
at 23:58:12.354 UTC, but no am_proc_start satisfying the parser.
Consequently its exact PID/self-directed signal cannot be established
from this available artifact; the warning screenshot remains conclusive
evidence of the earlier rendered loading UI.

## Technical interpretation

Switching Redroid's native Android version (12, 13, 14) is not enough to
eliminate the security warning from this unmodified Oxide APK.
The earlier Berberis MRS instruction failure applies to official x86_64
Google Play emulators and is **not** the cause of these native AArch64
loading-screen warning observations.

Precise security rejection cause is NOT IDENTIFIED. No Play Integrity
verdict was measured, no security mechanisms or APKs were modified, no
real player positions were captured and no actual multiplayer gameplay
or in-game ESP was confirmed.
