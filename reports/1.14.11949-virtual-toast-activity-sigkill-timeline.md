## Technical interpretation

1. The original Unity app enters Android Activity startup and the
   system displays a generic Toast window within ~0.7–0.9 seconds.
2. OxideActivity finishes 4.6–4.8 seconds after start.
3. The exact game PID sends SIGKILL 9 to itself ~45–53 ms later.
4. Android records death, followed by an Oxide package-owned Toast cleanup.
5. Changing four normal runtime permissions did not alter this sequence
   in any substantive way.
6. No explicit Unity Application.Quit log nor app-PID log entry with
   the Toast text was observed in the earlier PID-scoped warning audit.

**Still unknown:** which game component or external decision produced the
security toast, why it considered the virtual Android environment
unacceptable, or whether any single graphics / sensors / GMS warning
caused that decision. Event ordering and the Toast cleanup cannot
establish causation or identify the security vendor.

No original game's protection was patched, disabled, spoofed, hooked or
otherwise altered; no game-source player coordinates, multiplayer
session or playable ESP has been observed.
